# Agentic Coding — opencode

A hands-on workshop for getting productive with [opencode](https://opencode.ai), the open-source AI coding agent.

## What you'll do

1. Install opencode and connect it to GitHub Copilot.
2. Learn the TUI: modes, prefixes, slash commands, keybinds.
3. Go deeper: permissions, subagents, plugins.
4. Build something real in ~1–2 hours.

## Prerequisites

- A laptop with a modern terminal (Terminal.app, iTerm2, Windows Terminal, or your IDE's terminal).
- A GitHub Copilot license (acquired via the IT-Shop).
- ~2 hours.

If you need an LLM key instead of (or in addition to) Copilot, ask one of us — we have a virtual key for our internal LiteLLM instance.
