# Installation & Setup

## Prerequisites

* either CLI or UI-App from OpenCode installed
* Github Copilot from IT-Shop aquired

## Connect Github Copilot Provider

```
/connect
```
This will open a new window in your default browser, where you can log in with your GitHub account and authorize OpenCode to access your Copilot data. Once you have authorized the connection, you can start using the Copilot provider in OpenCode.
